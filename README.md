# esp32-dotmatrix-docs

`DotMatrixScroll` 예제의 공개 문서 사이트 — 일반 ESP32 WROOM DevKit로 MAX7219 8x8
도트 매트릭스 4개(직렬연결, 32x8 픽셀)를 구동해 커스텀 텍스트와 Wi-Fi/NTP 날짜·시간을
번갈아 스크롤하는 펌웨어. 소스 코드는 LilyGO T-Display-S3 예제 모음 저장소
(`examples/DotMatrixScroll/`, 로컬 전용)에 있고, 이 저장소는 그 문서(핀 배열, 배선도,
동작 방식, 라이브러리 목록)만 GitHub Pages로 공개합니다.

**문서 보기**: https://peter-cho-70.github.io/esp32-dotmatrix-docs/
