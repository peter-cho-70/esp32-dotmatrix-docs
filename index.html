DotMatrixScroll — ESP32 + MAX7219 8x8x4 스크롤 시계

소스: LilyGO T-Display-S3 examples 저장소 (examples/DotMatrixScroll/, 로컬 전용) — 문서만 별도의 public 문서 사이트로 발행합니다.

일반 ESP32 WROOM DevKit으로 MAX7219 8x8 도트 매트릭스 4개 직렬연결 모듈(32x8 픽셀)을 구동하는 예제. Wi-Fi/NTP로 시간을 동기화해 커스텀 텍스트·날짜·시간을 순서대로 스크롤하며, 날짜와 시간 화면은 각각 다 들어온 뒤 3초간 멈춥니다. T-Display-S3 보드 자체나 내장 화면은 사용하지 않습니다.

하드웨어

  • 일반 ESP32 WROOM DevKit (30핀)
  • MAX7219 8x8 LED 도트 매트릭스 모듈, 4개가 한 기판에 직렬(cascade)로 연결된 형태 (IN/OUT 표시, IN 쪽만 배선)

핀 배열 / 배선

모듈 입력(IN)측 5핀만 연결합니다. 4개의 매트릭스는 모듈 내부에서 이미 데이지체인으로 연결되어 있습니다.

MAX7219 모듈 핀ESP32 WROOM 핀비고
VCC5V (VIN)텍스트가 어둡거나 깜빡이면 별도 5V 전원 권장 — 4개 모듈 풀밝기 시 최대 ~1A
GNDGND별도 전원을 쓰더라도 ESP32 GND와 반드시 공통

GPIO0/2/12/15(부트 스트래핑 핀)은 피했습니다. GPIO0은 아래 Wi-Fi 설정용 BOOT 버튼으로 별도 사용됩니다 (부팅 완료 후에만 읽음). 글자가 뒤집히거나 깨져 보이면 모듈이 FC16_HW 타입이 아닐 수 있으니 소스의 HARDWARE_TYPE을 PAROLA_HW 또는 GENERIC_HW로 바꿔보세요.

동작 방식

  • 부팅 후 "WiFi..." 표시와 함께 네트워크 연결을 시도합니다.
  • WiFiManager로 Wi-Fi에 연결하며, 저장된 정보가 없으면 무한 대기 대신 설정용 AP를 엽니다.
  • 연결되면 NTP(pool.ntp.org, KST = UTC+9, DST 없음)로 시간을 동기화합니다.
  • 커스텀 메시지 → 날짜 → 시간 → (반복) 순서로 3개 화면을 순환합니다:
    1. 커스텀 메시지 (소스의 customMessage) — 짧게 정지 후 다음으로
    2. 날짜 — MM/DD(요일) 형식, 스크롤 시작 직전 매번 갱신, 다 들어온 뒤 3초 정지
    3. 시간 — HH:MM:SS 형식, 스크롤 시작 직전 매번 갱신, 다 들어온 뒤 3초 정지
  • Wi-Fi/NTP가 없으면 날짜/시간 화면은 조용히 건너뛰고 커스텀 메시지만 계속 스크롤합니다.

Wi-Fi 설정 흐름 (StockTicker / InfoTicker_LCD1602와 동일한 패턴)

  • 전원을 켤 때 BOOT 버튼(GPIO0)을 누르고 있거나, 동작 중 3초간 누르고 있으면 저장된 Wi-Fi 정보를 지우고 ESP32-DotMatrix(비밀번호 12345678)라는 설정용 AP를 엽니다.
  • 휴대폰/노트북을 그 AP에 연결하면 캡티브 포털이 자동으로 뜨거나(또는 192.168.4.1 접속), 거기서 Wi-Fi 네트워크를 선택합니다.
  • 포털은 180초 후 타임아웃되며, 아무도 설정을 마치지 않으면 오프라인 모드(메시지만 스크롤)로 넘어갑니다.

필요한 라이브러리

platformio.ini의 [env:DotMatrixScroll]에 선언:

  • majicdesigns/MD_Parola — 스크롤 텍스트 애니메이션
  • majicdesigns/MD_MAX72XX — MAX7219 드라이버
  • tzapu/WiFiManager — 캡티브 포털 방식 Wi-Fi 설정

빌드 / 업로드

pio run -e DotMatrixScroll -t upload

또는 VS Code에서 PlatformIO 사이드바 → DotMatrixScroll 환경 선택 → Upload. platformio.ini의 [platformio] default_envs가 DotMatrixScroll로 설정되어 있습니다.

커스터마이징

  • 메시지 텍스트: 소스의 customMessage 수정
  • 밝기: setup()의 display.setIntensity(3), 범위 0~15
  • 스크롤 속도: 상단의 SCROLL_SPEED(칸당 ms, 작을수록 빠름), SCROLL_PAUSE_MS(메시지 화면 뒤 정지시간), DATE_TIME_PAUSE_MS(날짜/시간 화면 뒤 정지시간, 기본 3000ms)
  • 시간대: configTime(9 * 3600, 0, ...)가 KST(UTC+9) 기준 — 다른 시간대는 오프셋 값을 변경
